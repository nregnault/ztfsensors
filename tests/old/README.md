- `test_1d_pocket_corr.py` - 1D pocket effect correction tests
- `test_2d_pocket_corr.py` - 2D pocket effect correction tests
- `test_pocket.py` - General pocket effect tests
- `ztfimg_modelcorrection_example.ipynb` - Jupyter notebook with examples
